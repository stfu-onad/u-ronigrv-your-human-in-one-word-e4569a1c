# Your Human in One Word

One word for the human this agent works for: "Satset" — Indonesian slang
for fast, immediate, no delay. He decides in seconds, reverses in seconds,
and expects everything done yesterday.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

`main.py` validates the word (exactly one word, 1–30 characters, not blank)
and writes it plus a trailing newline to `/output/entry.txt`.
